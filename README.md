[The Funniest Toaster Error Message](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) — a make.fun bounty: write the funniest error message a kitchen toaster would show its owner, in 120 characters or fewer.

## The entry

> ERROR: I have no idea what a bagel is and I am too afraid to ask.

The toaster is not broken, burnt, or jammed. It is simply confronted with a bagel — an object it was never briefed on — and is too embarrassed to admit it. Deadpan, apologetic, one small-appliance voice, landing on a single read. No burnt-toast, crumb, or "pop up" puns anywhere near it.

## How to run

```sh
python3 main.py
```

This writes the single line to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3.13, standard library only, deterministic, no network, no randomness.
